
# Port Authority Bus Terminal – Passenger Demand Analysis

## Project Overview
An academic Business Analytics project focused on understanding passenger demand patterns and supporting transportation capacity planning through data analysis and predictive modeling.

## My Role
Excel Regression Analysis & Exploratory Data Analysis

## Tools & Technologies
- Microsoft Excel
- Excel Data Analysis ToolPak
- Multiple Linear Regression
- Pivot Tables
- Exploratory Data Analysis (EDA)

## My Contributions
- Prepared the regression dataset.
- Created carrier and monthly dummy variables.
- Developed three multiple linear regression models.
- Compared model performance using R², RMSE, MAE and MAPE.
- Created carrier-wise and monthly EDA pivot tables.
- Interpreted factors associated with passenger demand.

## Regression Models
1. Basic Regression
2. Carrier Regression
3. Monthly Regression

## Key Results
- Best-performing model by test RMSE: Carrier Regression.
- Test RMSE: 1,248 passengers.
- Test MAPE: 14.4%.
- Previous-week passenger volume and bus departures were important predictors.

## Business Application
The analysis provides insights into carrier-level passenger demand and can support transportation service and capacity planning.

## Project Context
Collaborative academic project – BANL 6430, University of New Haven.
